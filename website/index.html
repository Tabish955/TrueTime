Trust & Security Transparency

Engineered for 100% False-Positive Immunity

Why legacy or generic single-file installers trigger false alarms on VirusTotal, and how TrueTime resolves it.

🏛️

Native Windows Installer (.MSI)

Distributed as an authentic Windows Installer MSI database built with the WiX 5 toolset. MSI packages are not executable PE wrappers and are completely immune to PE packer/crypter heuristic false positives.

📦

Unbundled Standard Assemblies

Generic .NET single-file bundles pack assemblies into the PE overlay of `apphost.exe`, which AI engines mistake for Trojan droppers (`Wacatac`, `ObfuscatedPoly`). TrueTime uses clean, unbundled native assemblies.

🛡️

Zero Shell Spawning

Unlike legacy batch files that trigger behavioral alerts by spawning `sc.exe` or `net stop w32time` from hidden scripts, TrueTime uses direct Win32 `advapi32.dll` API calls.

🔒

Enterprise Verification Notice

Every release binary is accompanied by verifiable SHA-256 cryptographic hashes below. TrueTime contains zero telemetry, zero adware, and no third-party network calls outside your configured NTP servers.
